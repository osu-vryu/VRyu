## What is VRyu?
VRyu is a virtual reality training game focused on teaching the practice, fundamentals, and traditional techniques of Kenjutsu, the Japanese art of the sword. The project is currently being developed by Computer Science seniors at Oregon State University as their Capstone Software Engineering Project, with a final release scheduled for June 2026.
